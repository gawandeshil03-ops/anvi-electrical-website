## Deploy on GitHub Pages

1. Create a GitHub repository, for example `anvi-electrical-website`.
2. Upload everything inside this folder to the repository root.
3. In GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**.
4. Wait for GitHub Pages to publish the site.
5. Replace every `https://YOUR-DOMAIN.example/` in:
   - `index.html`
   - `robots.txt`
   - `sitemap.xml`
   with the final website URL.
6. If using a custom domain, add it in **Settings → Pages → Custom domain** and configure the DNS records at your domain provider.
7. In Google Search Console, add the final domain/property, verify ownership, submit `sitemap.xml`, and use URL Inspection to request indexing.
